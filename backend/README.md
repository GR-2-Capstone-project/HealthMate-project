# HealthMate

## 1. Project Overview

HealthMate is a healthcare technology application designed to help users organise and manage their personal medication routines.

The application enables users to manage medication schedules, receive reminders, record medication activities and review their medication history.

## 2. Project Objectives

To provide users with a simple and accessible platform for organising their medication routines and monitoring their medication activities.

## 3. Core Features

- User registration and authentication
- Medication management
- Medication scheduling
- Medication reminders
- Recording medication as taken or missed
- Medication activity history
- Personal dashboard

## 4. Project Scope

HealthMate focuses on personal medication routine management.

The application does not provide medical diagnosis, treatment recommendations or prescription advice.
